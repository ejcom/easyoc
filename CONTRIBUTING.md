# Contributing Guide

Thank you for your interest in EasyOC! We welcome your contributions and suggestions.

## How to Contribute

1. Fork the repository
2. Create your feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Commit your changes (`git commit -m 'Add some amazing feature'`)
5. Push to your fork (`git push origin feature/amazing-feature`)
6. Create a Pull Request

## Code Standards

- Use 4-space indentation
- Comment code in English
- Follow existing code style
- Add tests for new features
- Update documentation as needed

## Reporting Issues

When creating an issue, please:
- Use the issue template
- Describe the problem in detail
- Specify the script version
- Attach error logs if available

## Questions and Discussions

Use Discussions in the repository for questions and ideas.
